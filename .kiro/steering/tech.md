# Tech Stack

Frontend: React (Vite), JavaScript, plain CSS. Backend: Python, FastAPI. Database: MongoDB Atlas with PyMongo. Auth: email and password, bcrypt, JWT. Video storage: local folder backend/storage/videos. Speech to text: Whisper via Groq API. LLM: Groq API with JSON output. Audio: ffmpeg. Background work: FastAPI BackgroundTasks. Secrets only in .env files. Do not use OpenCV, MediaPipe or webcam features.
